# i18n pt/en/es — Fase 56 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Localizar o app em **pt-BR / en / es** com gen_l10n (ARB), acesso por `context.l10n`, seletor de idioma persistido, e migrar toda a UI, os testes e o widget nativo.

**Architecture:** `flutter gen-l10n` (ARB) gera `AppLocalizations`; uma extensão `context.l10n` substitui `AppStrings`; um provider `idiomaProvider` escolhe o locale e o `MaterialApp` o aplica. Camadas não-UI não localizam texto (a UI fornece).

**Tech Stack:** Flutter, `flutter_localizations`/`intl`, Riverpod, SharedPreferences.

**Spec:** `docs/superpowers/specs/2026-09-30-i18n-design.md` (RF-39 / Fase 56)

## Global Constraints

- 100% local; **sem dependência nova** (`flutter_localizations`/`intl` já no `pubspec`).
- `pt` é **template e fallback**; `en` e `es` são traduções completas.
- **Nada de i18n em camadas não-UI** (parser, repositórios, providers, domínio): a UI fornece o texto.
- **Formatação** de número/data/moeda **não muda** (continua pt-BR).
- `pt-BR` na UI/testes; nomes de teste `deve_<resultado>_quando_<condição>`.
- `dart format . && flutter analyze && flutter test` verdes a cada tarefa; a suíte roda em **pt-BR**.
- Não alterar dados/Drift/parser/IDs.

**Interfaces you produce (Tasks 2–5 depend on these):**

- `idiomaProvider` (`AsyncNotifierProvider<IdiomaNotifier, IdiomaApp>`), enum `IdiomaApp { sistema, pt, en, es }`, persistido em SharedPreferences na chave `idioma_app`, com `Locale? get locale` (`null` = sistema).


- [ ] **Step 2: Portar `AppStrings` para o ARB (pt)** — converter cada membro de `AppStrings` numa chave ARB:
  - `static const x = 'texto'` → `"x": "texto"`.
  - métodos com parâmetros → chaves com `placeholders` (ex.: `"nItens": "{n, plural, =1{1 item} other{{n} itens}}"` com `@nItens`).
  - converter os textos **plurais** para ICU `plural` (ex.: `itensExtraidos(n)`, `progressoLista`, `mercadoProgresso`, `totalComOrcamento`, `tourPasso`, etc.).
  - incluir o texto da **política de privacidade** (`politica_privacidade.dart`).
- [ ] **Step 3: Traduções en/es** — `app_en.arb` e `app_es.arb` com **todas** as mesmas chaves. Mesmos placeholders/plurais.
- [ ] **Step 4: gerar** — Run: `flutter gen-l10n` (ou `flutter pub get`); confirme `lib/l10n/app_localizations*.dart`.
- [ ] **Step 5: extensão + app wiring** — `lib/core/l10n/l10n.dart`:

```dart

import '../../l10n/app_localizations.dart';

```

`lib/app.dart`: `localizationsDelegates: AppLocalizations.localizationsDelegates` (junto dos `GlobalMaterial...`), `supportedLocales: AppLocalizations.supportedLocales` (`[pt, en, es]`), `locale: ref.watch(idiomaProvider).value?.locale` (null = sistema).
